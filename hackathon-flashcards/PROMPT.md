# Hackathon Prompt Engineering

**Tool used:** Claude (AI Assistant)

**The Prompt:**
"Create a responsive flashcard app for studying Azure cloud concepts. Use HTML, CSS, and vanilla JavaScript. It should have a single card that flips on click (3D flip animation). Front shows the question, back shows the answer. Include 'Next', 'Previous', and 'Shuffle' buttons. Add a progress indicator (e.g., 'Card 1 of 5'). Make the design clean, modern, and mobile-friendly using a blue and white color scheme. Do not use any Microsoft or Azure logos."

**Why I chose this design:**
I wanted a clean, distraction-free interface. The 3D flip animation provides a satisfying tactile feel that mimics physical flashcards. The shuffle button allows users to randomize their study sessions, which improves retention.
